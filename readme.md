# Festa

AI Copilot for Weddings, Birthdays and Community Events

## MVP Features

- Event planning for weddings, birthdays, community events and corporate events
- Cost estimation and budget allocation
- Timeline with real dates and an event checklist
- AI risk prediction, cost optimisation and vendor planning ranges
- AI confidence score and sustainability score
- Voice narration with Start, Pause and Stop (about 3 minutes)

## How It Works

1. Select the event type
2. Enter guests, budget, event date and city
3. Click Generate Plan to see the scores, timeline, budget breakdown, checklist and AI insights
4. Click Start Narration to hear complete event guidance

## Run It

Open `index.html` in Chrome, Edge or Safari with your sound on. No install or build step is needed.

## Get Your MVP Link

Deploy the single `index.html` to any one of these:

- **GitHub Pages:** create a repository, upload the four files, open Settings, then Pages, choose the main branch and root folder, and save. Your link will be `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.
- **Netlify:** drag the folder onto the Netlify Drop page, and a link is created immediately.
- **Vercel:** import the GitHub repository, keep the default settings, and deploy.

## How the Scores Work

- **Budget confidence** starts at 90 and changes with budget per guest, time left and guest count.
- **Budget risk** compares the extra food cost of 15 percent more guests with the reserve in the budget split.
- **Sustainability** is 55 plus 10 for each practice selected, out of 100.
- **Potential savings** is 12 percent of the venue budget.

These are transparent, rule-based planning estimates and not quotes. Always get written quotes from vendors.
